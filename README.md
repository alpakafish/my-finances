# Мои финансы

Локальный веб-сервис учёта личных расходов и доходов. Запускается одной командой на своём компьютере, все данные хранятся в SQLite-файле рядом с проектом — ничего не уходит в облако.

## Проблема

Ручной учёт бюджета в Excel-таблице каждый месяц: нужно самостоятельно заводить строки, копировать формулы, пересчитывать проценты по категориям и обновлять графики — рутина, которая отнимает время и легко ломается при опечатке в формуле.

## Пользователь

Один человек (или семья), который ведёт личный/семейный бюджет и хочет вносить траты и доходы за минуту, а не открывать и чинить таблицу.

## Основная функция

- **Вход**: ручной ввод операции — дата, тип (расход/доход), категория, сумма, заметка.
- **Обработка**: операции сохраняются в SQLite; категории можно заводить, переименовывать, перекрашивать и удалять (с переносом операций на другую категорию, если категория уже использовалась).
- **Выход**: отчёт за выбранный месяц (доход / расход / баланс, разбивка расходов по категориям, круговая диаграмма структуры расходов), обзорный график расходов по последним месяцам, и экспорт всех данных в Excel одной кнопкой.

## Формат результата

Веб-страница (открывается в браузере на `localhost:3000`) с четырьмя вкладками — Дашборд, Операции, Категории, Цели — плюс кнопка «Экспорт в Excel», которая скачивает `.xlsx` с листом всех операций и сводкой по месяцам.

## Минимальный функционал (MVP)

Реализовано:
- CRUD операций (добавление, просмотр по месяцам с фильтром «Все/Расходы/Доходы», удаление)
- CRUD категорий расходов и доходов (добавление, переименование, смена цвета, удаление с переносом операций)
- Отчёт за месяц с диаграммами (Chart.js) — расходы по категориям, структура расходов, расходы и доходы по месяцам
- Рекомендации по категориям — если расходы/доходы в категории выросли или упали более чем в 1,5 раза по сравнению с прошлым месяцем или средним за 3 месяца (или категория впервые появилась/пропала), об этом пишет отдельная плашка под графиком
- Цели накопления (вкладка «Цели», по образцу накопительного счёта с целью) — сумма, необязательный срок в месяцах с автоматическим пересчётом «сколько откладывать в месяц» по мере взносов, кольцо прогресса, быстрый взнос. Цель привязывается к существующей категории расходов или к новой (например «на ноутбук и айфон»), которую можно «подшить» к другой категории (обычно «Сбережения») — так операция видна как есть в списке операций, а на Дашборде и в Excel-сводке суммируется в целевую категорию
- Импорт из Excel (`exceljs` + `multer`) — загружает листы «Траты…»/«Приход…» из существующей таблицы, с защитой от повторного добавления одних и тех же строк; формат описан в тултипе на кнопке «Импорт из Excel» на дашборде
- Экспорт в Excel (`exceljs`)
- Локальное хранилище — SQLite-файл `data/smeta.db`, ничего не отправляется во внешние сервисы

Не реализовано (возможные следующие шаги): редактирование уже добавленной операции (сейчас только удаление и повторное добавление), мультивалютность, бюджеты/лимиты по обычным категориям с уведомлениями (сейчас лимиты есть только у целей накопления).

## Технологии

Node.js, Express, better-sqlite3, ванильный HTML/CSS/JS, Chart.js (подключён локально, без интернета), ExcelJS для экспорта в `.xlsx`.

## Как запустить

Нужен установленный [Node.js](https://nodejs.org/) (18 или новее).

```bash
cd smeta-web
npm install
npm start
```

Откроется сервер на [http://localhost:3000](http://localhost:3000) — откройте эту ссылку в браузере.

Либо на Mac просто дважды кликните `start.command` (на Windows — `start.bat`): скрипт сам поднимет сервер и откроет браузер.

Данные хранятся в `smeta-web/data/smeta.db` — это обычный файл, его можно скопировать для бэкапа или перенести на другой компьютер вместе с папкой проекта.

Чтобы остановить сервер — закройте терминал/окно скрипта или нажмите `Ctrl+C`.
