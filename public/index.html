Локальный учёт расходов и доходов

Формат файла для импорта (.xlsx)
  • Лист с расходами — название начинается с «Траты…», с доходами — с «Приход…» (остальные листы, например «Итого», пропускаются)
  • 1-я строка — любой заголовок, 2-я — подписи столбцов (обе игнорируются), данные — с 3-й строки
  • Столбцы по порядку: A — дата, B — сумма, C — заметка (необязательно), D — категория (необязательно, иначе попадёт в «Другое»/«Прочий доход»)
  • Строки без даты или суммы пропускаются
  • Повторный импорт того же файла безопасен — точные дубли не добавляются
