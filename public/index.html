Формат файла для импорта (.xlsx)
  • Файл, скачанный кнопкой «Экспорт в Excel» — из него, наоборот, восстановятся все те же операции: удобно для переноса на другое устройство или бэкапа
  • Либо ручная таблица: лист с расходами — название начинается с «Траты…», с доходами — с «Приход…» (остальные листы, например «Итого», пропускаются); 1-я строка — любой заголовок, 2-я — подписи столбцов (обе игнорируются), данные — с 3-й строки; столбцы по порядку — A: дата, B: сумма, C: заметка (необязательно), D: категория (необязательно, иначе попадёт в «Другое»/«Прочий доход»)
  • Строки без даты или суммы пропускаются
  • Повторный импорт того же файла безопасен — точные дубли не добавляются
Скачает .xlsx с двумя листами: «Операции» — все записи построчно, и «Сводка по месяцам» — суммы по категориям и месяцам. Этот же файл можно загрузить обратно через «Импорт из Excel» — на этом или на другом устройстве, — чтобы перенести данные или сделать бэкап.

Общий бюджет на месяц ?
Необязательный лимит на все расходы за месяц вместе взятые — в отличие от лимитов ниже, каждый из которых про одну категорию. Считается так же, как «Расход» в отчёте за месяц: без операций с пометкой «нал.». Прогресс отобразится на Дашборде, уведомление — при приближении и превышении, как у лимитов категорий.
Лимиты категорий расходов ?
  • Лимит можно указать на месяц, на год или оба сразу
  • Месячный лимит — прогресс отобразится на Дашборде
  • Годовой лимит — прогресс отобразится на вкладке «По годам»
  • Считается только сумма операций по категории, для которой указан лимит, без «подшитых» к ней целей (например, создали цель с категорией «Отпуск», расходы по которой считаются как «Сбережения»: лимит будет рассчитываться только для категории «Отпуск»)

Автоматические бэкапы ?
Раз в день, при открытии приложения, автоматически сохраняется копия всех данных — хранятся последние 7. Восстановить — через «Импорт из Excel», выбрав нужный файл.
